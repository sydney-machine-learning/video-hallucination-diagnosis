# Results

- `figures/` contains the final Accuracy, PDI, HCE, source-split, and category heatmap figures.
- `tables/` contains the scored item table, clip-level metrics, and aggregate summaries generated by the scripts.
- `case_examples/` contains matched original, reversed, and masked frame sequences for one real and one AI-generated fire video.

Quantitative files can be regenerated with `scripts/generate_all_results.py`.
The case-example images are fixed qualitative assets and are not regenerated by
that script.
